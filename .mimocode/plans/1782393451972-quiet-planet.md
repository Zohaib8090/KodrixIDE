# Plan: Pixel-Perfect Desktop UI Matching Android

## Goal
Make the desktop UI look exactly like the Android mobile version. Same colors, same layout, same icons, same spacing, same animations.

## Android UI Structure (Reference)
```
┌─────────────────────────────────────────────────┐
│ 48dp ActivityBar │ 280dp Sidebar │  Editor Area │
│  #161B22         │  #161B22      │  #0D1117     │
│                  │               │  Tab Bar     │
│  [Projects]      │  Content      │  35dp #161B22│
│  [Explorer]      │  changes per  │              │
│  [Git]           │  sidebar mode │  Code Editor │
│  [Search]        │               │              │
│  [Extensions]    │               │              │
│  [Marketplace]   │               │              │
│  [AI]            │               │              │
│  [Terminal]      │               │──────────────│
│  [Debug]         │               │ Bottom Panel │
│  [Browser]       │               │ Terminal     │
│  [Settings]      │               │              │
└─────────────────────────────────────────────────┘
│              Status Bar 24dp                      │
```

## Key Design Tokens
- Background: `#0D1117`
- Surface: `#161B22`
- Outline/Border: `#30363D`
- Primary/Accent: `#58A6FF`
- Text: `#C9D1D9`
- Muted text: `#8B949E`
- Success: `#238636`
- Error: `#F85149`
- Warning: `#E3B341`
- ActivityBar width: `48dp`
- Sidebar width: `280dp`
- Tab bar height: `35dp`
- Title bar height: `32dp`
- Status bar height: `24dp`
- Font: Monospace for code, System for UI
